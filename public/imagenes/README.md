# Carpeta de Imágenes JOLY

Coloca aquí las imágenes oficiales de los productos en formato PNG o JPG.

Archivos prioritarios identificados:
- `cassata-piña.png`
- `cassata-tradicional.png`
- `cassata-trisabor.png`

La aplicación detectará automáticamente cuando un archivo exista en esta carpeta y lo mostrará sin distorsión.
Si un archivo aún no ha sido cargado, la tienda mostrará una presentación visual limpia y profesional con la información del producto.
